Devices & the plan.

How it connects

  • One phone per family member running the RxPulse app
  • Rings, bands and watches pair through Health Connect (Android) and HealthKit (iOS)
  • Background sync of heart rate, steps, sleep and screen use
  • Sleep is inferred from phone off / on times plus wearable data
  • Everything is written to the database every week

AI you plug in

  • Food photo → calories: vision model + verified food table
  • Prescription photo → reminders: OCR + LLM, user confirms, push notification, Yes / No check
  • Recovery coach: LLM using steps, sleep and heart data against the goal (lose, maintain, gain)
  • Keys stay on the server only

Database

  • PostgreSQL via Prisma: Family, Member, Device, Vital, SleepLog, MealLog, Medication, DoseLog, WeeklySummary
  • Object storage for photos, links only in the DB
  • Per-member consent and roles

General information only. RxPulse is not a medical device and does not diagnose or treat.
